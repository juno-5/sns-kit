4 · 인스타그램 생성 순서

  1. 모바일 앱에서 로그아웃 → 새 계정 만들기 (웹 가입 X — 차단률 높음)
  2. 이메일로 가입 (전화번호 X) · 개인계정에 "계정 추가"로 붙이지 말 것
  3. 핸들·생년월일 입력 → 가입 직후 2FA 설정
  4. 설정 → 계정 유형 및 도구 → 프로페셔널 → 비즈니스 (크리에이터 아님) → 카테고리 앱 페이지
  5. 연락처: 이메일 ON support@mayacrew.co.kr / 전화·주소 OFF
  6. 액션 버튼 → 앱 다운로드 + 어트리뷰션 원링크
  7. business.facebook.com → 페이지 연결 · 앱 등록(SKAN) · 광고 계정은 앱별로 분리
  8. 두 계정은 24시간 간격으로 생성 · 프로필은 2~3일 나눠 채우기
